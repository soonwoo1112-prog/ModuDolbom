# 모두돌봄 랜딩 페이지 (시안)

보호자와 시터에게 모두돌봄을 소개하고 출시 알림 신청을 받는 한 장짜리 웹페이지입니다. Taste 스킬(design-taste-frontend)의 과정대로 만들었고 마무리 검사(gate)를 통과했습니다.

- `index.html`: 페이지. `img/screens/`는 앱 미리보기에서 찍은 실제 화면, `img/`의 사진은 창업자가 찍은 강아지 사진입니다.
- `assets/`: Taste 스킬의 페이지 키트 중 이 페이지가 쓰는 파일만 담았습니다(MIT, `assets/LICENSE-taste-skill`).
- `fonts/`: IBM Plex Sans KR(SIL Open Font License)을 이 페이지에 쓰인 글자만 남겨 줄인 파일입니다. 문구를 바꾸면 다시 줄여야 합니다.
- 출시 알림 신청서는 아직 받을 곳이 없어 `hello@modudolbom.example`로 보내도록 되어 있습니다. 실제 받을 주소나 폼 서비스를 정하면 `data-endpoint`에 넣으세요.
