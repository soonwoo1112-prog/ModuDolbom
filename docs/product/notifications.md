# 알림

- 작성일: 2026-11-11
- 함께 보기: [예약·산책 흐름](booking-flow.md)
- 문구는 예시다. 짧은 해요체로 쓰고, 최종 문구는 디자인 세션에서 다듬는다.

## 1. 보호자가 받는 알림

### 예약·산책

| 언제 | 문구 예시 | 누르면 |
|---|---|---|
| 시터가 요청을 수락해 대화창이 열렸을 때 | 이○○ 시터님이 대화를 시작했어요 | 그 대화창 |
| 새 메시지가 왔을 때 | 이○○ 시터님: (메시지 내용) | 그 대화창 |
| 시터가 먼저 확정했을 때 | 이○○ 시터님이 산책을 확정했어요. 확정을 누르면 예약이 완료돼요 | 그 대화창 |
| 산책 당일 아침 | 오늘 오후 3시에 보리 산책이 있어요 | 예약 정보 |
| 시터가 산책을 시작했을 때 | 보리 산책이 시작됐어요. 지금 어디쯤인지 볼까요? | 실시간 위치 보기 |
| 산책이 끝났을 때 | 보리가 산책을 마쳤어요. 산책 기록을 보고 후기를 남겨 주세요 | 산책 기록과 후기 |

### 소셜

| 언제 | 문구 예시 | 누르면 |
|---|---|---|
| 내 글에 좋아요가 달렸을 때 | 박○○님이 내 글을 좋아해요 | 그 글 |
| 내 글에 댓글이 달렸을 때 | 박○○님이 댓글을 남겼어요: (댓글 내용) | 그 글의 댓글 |

## 2. 시터가 받는 알림

### 예약·산책

| 언제 | 문구 예시 | 누르면 |
|---|---|---|
| 새 요청이 왔을 때 | 김○○ 보호자님이 11월 14일(금) 오후 3시 산책을 요청했어요 | 새 요청 자세히 |
| 새 메시지가 왔을 때 | 김○○ 보호자님: (메시지 내용) | 그 대화창 |
| 보호자가 먼저 확정했을 때 | 김○○ 보호자님이 산책을 확정했어요. 확정을 누르면 예약이 완료돼요 | 그 대화창 |
| 보호자가 후기를 남겼을 때 | 김○○ 보호자님이 보리 산책 후기를 남겼어요 | 받은 후기 |

| 내 산책 기록이나 글에 댓글이 달렸을 때 | 박○○님이 댓글을 남겼어요: (댓글 내용) | 그 글의 댓글 |

## 3. 추가를 제안하는 알림 (Claude)

위 목록에 더하면 좋을 알림들. 채택 여부를 정해야 한다.

### 둘 다 받는 알림

| 언제 | 받는 사람 | 문구 예시 | 이유 |
|---|---|---|---|
| 둘 다 확정해 예약이 완료됐을 때 | 보호자, 시터 | 11월 14일(금) 오후 3시 보리 산책이 확정됐어요 | 마지막에 확정한 사람도 결과를 확인해야 함 |
| 예약 수정 요청이 왔을 때 | 상대방 | 김○○ 보호자님이 예약 시간 변경을 요청했어요 | 수정은 상대 동의가 필요함 |
| 예약이 취소됐을 때 | 상대방 | 11월 14일 보리 산책이 취소됐어요 | 취소를 놓치면 노쇼로 이어짐 |

### 보호자만

| 언제 | 문구 예시 | 이유 |
|---|---|---|
| 결제가 완료됐을 때 | 보리 산책 결제가 완료됐어요 (15,000원) | 돈이 나간 건 반드시 알려야 함 |
| 결제가 실패했을 때 | 결제가 되지 않았어요. 결제 수단을 확인해 주세요 | 결제가 안 되면 예약이 성립하지 않음 |
| 요청한 시터가 모두 거절했거나 오래 응답이 없을 때 | 아직 대화를 시작한 시터가 없어요. 다른 시터에게도 요청해 볼까요? | 보호자가 기다리기만 하는 상황을 막음 |

### 시터만

| 언제 | 문구 예시 | 이유 |
|---|---|---|
| 산책 당일 아침 | 오늘 오후 3시에 보리 산책이 있어요. 픽업 안내를 확인해 주세요 | 시터의 노쇼 방지가 더 중요함 |
| 산책 시작 시간이 됐는데 시작을 누르지 않았을 때 | 산책을 시작할 시간이에요. 시작 버튼을 눌러 주세요 | 시작을 안 누르면 보호자가 위치를 못 봄 |
| 다른 시터로 확정되어 요청이 닫혔을 때 | 김○○ 보호자님의 요청이 마감됐어요 | 기다리던 시터가 헛수고하지 않게 함 |
| 정산이 완료됐을 때 | 이번 주 정산 45,000원이 입금됐어요 | 프리랜서에게 가장 중요한 알림 |
| 가입 심사 결과가 나왔을 때 | 시터 가입이 승인됐어요. 이제 요청을 받을 수 있어요 | 가입 직후 이탈 방지 |

## 4. 알림 설정과 규칙

- **알림 끄기:** 더보기 > 설정에서 종류별로 켜고 끌 수 있게 한다. 예: 메시지, 예약·산책, 소셜, 혜택·소식.
  - 예약·산책 알림은 서비스 이용에 꼭 필요하므로, 끄려 할 때 한 번 더 안내한다.
- **광고성 알림:** 할인이나 이벤트 같은 광고성 알림은 별도 수신 동의가 필요하다. 밤 9시부터 아침 8시까지는 따로 동의를 받아야 보낼 수 있다(정보통신망법). 예약·산책 알림처럼 서비스 이용에 필요한 알림은 여기에 해당하지 않는다.
- **당일 아침 알림 시간:** 예를 들어 아침 8시에 보낸다. 산책이 아침 9시 이전이면 전날 저녁에 보낸다.
- **소셜 알림 묶기:** 좋아요가 한꺼번에 많이 달리면 "박○○님 외 5명이 내 글을 좋아해요"처럼 묶어서 보낸다.
- **앱 안 알림 목록:** 푸시로 보낸 알림은 앱 안의 알림 화면(캔버스 17)에도 쌓인다.
