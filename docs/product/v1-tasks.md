- 근거: [첫 출시 범위와 기술 과제](mvp-scope.md), [예약·산책 흐름](booking-flow.md), [알림](notifications.md)

과제를 누가 하는지에 따라 네 묶음으로 나눴다. 디자인 과제는 위에서부터 차례로 진행한다. 행정 절차는 기간이 오래 걸려서 디자인·개발과 동시에 시작한다.

## 1. 디자인 (캔버스와 미리보기)

### 1-1. 이미 결정된 것 맞추기 (booking-flow.md "결정된 사항")

- [x] 산책 길이를 강아지 다음 단계로 옮기기 (강아지 → 길이 → 날짜 → 시간 → 만나는 곳)
- [x] 둘 다 확정해야 예약 완료: 보호자 채팅과 시터 채팅 모두에 확정 버튼, 한쪽만 확정했을 때의 안내
- [x] 확정 순간 결제: 보호자가 확정할 때 결제 금액과 결제 수단을 보여 주는 확정 시트
- [x] `PRODUCT.md`의 "보호자가 확정"을 "둘 다 확정"으로 고치기

### 1-2. 모든 흐름에 필요한 공용 화면

- [x] "준비 중" 안내 시트: 예약 정보의 산책 보험, 산책중 지도의 추천 경로. "알림 받기" 버튼
- [x] 상태 화면: 아무도 수락하지 않은 요청 현황, 모두 취소한 요청 현황 (오류와 내용 없음은 디자인 시스템 ListStates를 따름)
- [x] 권한 요청: 위치(시터의 "항상 허용" 안내 포함), 알림, 사진. 왜 필요한지 먼저 설명하고 휴대폰 권한 창을 띄움
- [x] 개인위치정보 이용 동의 (초안, 약관 전문은 법무 검토 뒤)

### 1-3. 계정

- [x] 로그인·회원가입 (카카오, 네이버, Apple). 버튼의 로고는 자리만 잡음, 각 사 로고 가이드대로 교체
- [x] 보호자·시터 역할 선택
- [x] 본인 인증, 거주지(동네·같은 아파트) 인증. 같은 아파트는 선택
- [x] 시터: 계좌 인증(1원 입금), 시팅 팁 퀴즈(4문제, 출시 전 훈련사·수의사 검토), 가입 심사 대기, 승인 화면. 승인 알림 문구는 notifications.md

### 1-4. 결제와 취소

- [x] 결제 수단 관리, 보호자 결제 내역 (더보기에서 들어감)
- [x] 시터의 예약·취소 규정: 서비스 설정에서 정하고, 시터 프로필 가격 탭에 보임
- [x] 취소·환불 화면: 무료 기간, 24시간 전까지(30%), 24시간 안(50%) 세 가지. 확정된 예약의 채팅 더보기에서 들어감
- [x] 노쇼 신고: 보호자용과 시터용. 채팅 더보기에서 들어감. 전화를 걸어 본 뒤에 신고할 수 있음

- [ ] 고객센터: 카카오톡 채널 연결
