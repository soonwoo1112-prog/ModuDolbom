# 산책 기능

산책 중과 산책 후에 시터와 보호자가 쓰는 기능.

## 1. 산책 시작

- 시터는 "오늘" 탭의 예약에서 **한 번 터치로 산책을 시작**한다. 이때 GPS 기록이 함께 시작된다.

## 2. 산책 중

- **AI 추천 산책 경로:** 시터의 출발 지점을 기준으로 산책 경로를 추천한다.
- **실시간 GPS:** 정확한 위치 추적으로, 보호자가 산책 중인 강아지가 지금 어디 있는지 확인할 수 있다.

## 3. 산책 후: 산책 로그

산책이 끝나면 아래 내용을 기록으로 남긴다.

- 사진
- GPS로 기록된 경로
- 배변 횟수 등 강아지 상태

산책 로그는 보호자가 공유를 허용하면 [소셜 피드](social.md)에 올릴 수 있다.
