# 로고 애니메이션

디자인 시스템 "모두돌봄"의 Logos 에셋(`modudolbom-symbol.svg`)을 그대로 써서 만든 3.2초, 60fps 로고 모션입니다. 릴스 엔딩, 광고 마지막 장면, 프로필 영상에 씁니다.

## 움직임

| 시간 | 동작 |
|---|---|
| 0.00s | 사람(큰 원)이 통통 튀며 나타남 |
| 0.24s | 강아지 발바닥이 나타남 |
| 0.56s~ | 발가락 세 개가 왼쪽부터 차례로 톡톡톡 |
| 0.92s | 웃는 입이 왼쪽에서 오른쪽으로 그려짐 |
| 1.50s | 심볼 전체가 한 번 끄덕이며 웃음 |
| 1.56s | 워드마크 "모두돌봄", 이어서 "우리 동네 산책 이웃" |
| 2.3~3.2s | 정지 화면 유지 |

## 결과물 (`out/`)

| 파일 | 크기 | 용도 |
|---|---|---|
| `logo-reel-light.mp4` | 1080×1920 흰 바탕 | 릴스·스토리 엔딩 |
| `logo-reel-brand.mp4` | 1080×1920 숲 초록 바탕 | 릴스·스토리 엔딩(강조) |
| `logo-square-light.mp4` | 1080×1080 흰 바탕 | 피드 광고, 프로필 |
| `logo-square-brand.mp4` | 1080×1080 숲 초록 바탕 | 피드 광고, 프로필 |

같은 이름의 `.png`는 마지막 프레임(정지 로고)입니다.

## 다시 만들기

```bash
./build.sh
```

- `render.js`: Playwright로 HTML/SVG 애니메이션을 프레임마다 멈춰 PNG로 렌더합니다. 타이밍과 색, 크기는 이 파일에서 바꿉니다.
- `build.sh`: Pretendard(Bold, Medium)를 npm에서 받아오고, 네 가지 버전을 렌더한 뒤 ffmpeg로 mp4를 만듭니다.
- 색: 심볼은 원본 SVG 색 `#00733a`, 글자는 디자인 시스템 `fg-neutral` / `fg-neutral-muted` 토큰입니다.
- 서체: 디자인 시스템 규칙대로 워드마크 Bold 700, 태그라인 Medium 500입니다.
