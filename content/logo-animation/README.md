# 로고 애니메이션

디자인 시스템 "모두돌봄"의 Logos 에셋(마크 "나란히 걷기" `modudolbom-mark.svg`, SUIT 워드마크 `modudolbom-wordmark.svg`)을 그대로 써서 만든 로고 모션입니다. 릴스 엔딩, 광고 마지막 장면, 프로필 영상에 씁니다.

## 확정본: `popin/` (2026-11-11)

**릴스, 광고, 프로필 영상의 로고 모션은 `popin/`을 씁니다.** 다른 버전은 비교와 기록용으로만 남겨 둡니다.

| 파일 | 크기 |
|---|---|
| `popin/out/logo-popin-reel-4k.mp4` | 9:16, 2160×3840 |
| `popin/out/logo-popin-reel-1080.mp4` | 9:16, 1080×1920 |
| `popin/out/logo-popin-square-4k.mp4` | 1:1, 2160×2160 |
| `popin/out/logo-popin-square-1080.mp4` | 1:1, 1080×1080 |

벡터로 그린 3.5초, 60fps 모션입니다. 큰 원 → 작은 원 → 길 스와이프 → 쉼 → 발가락 셋 팝업 → 마크가 올라가며 "모두돌봄"과 "이웃과 나란히 걷는 산책"이 나타납니다. 자세한 타이밍은 `popin/README.md`에 있습니다.

## 지난 버전 (기록용)

| 폴더 | 내용 | 쓰지 않는 이유 |
|---|---|---|
| `out/` (이 폴더의 `render.js`) | 위에서 떨어지며 눌리고 튀는 코드 버전, 태그라인 "우리 동네 산책 이웃" | 낙하·탄성 대신 제자리 팝업으로 결정 |

| `gemini/` | Gemini Omni Flash 1.2, 팝업 3초 | 프레임 끊김, AI 느낌, 태그라인 오타 |

## 지난 버전 상세

### 1. Higgsfield 버전 (`higgsfield/`, 6.4초) — 기본으로 쓰는 버전

큰 원이 액체처럼 철퍽 떨어졌다가 다시 뭉치고, 작은 원이 튀어 들어오고, 아래 길이 그려진 뒤, 잠깐 쉬고 발가락 셋이 톡톡톡 찍힙니다. 마지막에 다 같이 한 번 크게 늘어났다가 자리를 잡습니다.

- 생성: Seedance 2.0 Mini, 720p, 5초, 5크레딧. 시작 프레임(빈 흰 화면), 끝 프레임(정확한 마크), 움직임 참고 영상(아래 코드 버전의 마크만)을 함께 넣었습니다.
- 합성(`higgsfield/build.sh`): 1080×1920 업스케일, 배경을 순백으로 보정, 4.45초부터 정확한 벡터 마크로 크로스페이드, 워드마크와 태그라인은 벡터로 얹습니다. 그래서 끝 화면은 로고 원본과 같습니다.
- 결과: `higgsfield/out/logo-ai-reel-light.mp4`(9:16), `logo-ai-square-light.mp4`(1:1)

### 2. 코드 버전 (`out/`, 3.8초)

같은 순서를 코드로 그린 버전입니다. 크레딧 없이 색과 비율을 바꿔 바로 다시 뽑을 수 있고, Higgsfield에 넣는 움직임 참고 영상으로도 씁니다.

| 시간 | 동작 |
|---|---|
| 0.00s | 큰 원(사람)이 떨어져 눌렸다가 튀어 오르며 자리 잡음 |
| 0.26s | 작은 원(발바닥)이 같은 방식으로 |
| 0.62s | 아래 웃는 길이 왼쪽에서 오른쪽으로 그려짐 |
| 1.50s~ | 잠깐 쉬고, 발가락 셋이 왼쪽 · 위 · 오른쪽 순서로 꾹 찍힘 |
| 2.26s | 마크 전체가 한 번 끄덕임 |
| 2.38s | 워드마크, 이어서 "우리 동네 산책 이웃" |

## 다시 만들기

```bash
./build.sh              # 코드 버전 4종
./higgsfield/build.sh   # Higgsfield 버전 합성 (원본 영상은 higgsfield/source-seedance-a.mp4)
```

- `render.js`: Playwright로 HTML/SVG 애니메이션을 프레임마다 멈춰 PNG로 렌더합니다. 타이밍과 색, 크기는 이 파일에서 바꿉니다.
- `build.sh`: 네 가지 버전을 렌더한 뒤 ffmpeg로 mp4를 만듭니다.
- 색: 마크 `#00733a`, 워드마크 `#141a16`(디자인 시스템 에셋 그대로), 태그라인 `fg-neutral-muted`.
- 워드마크는 디자인 시스템의 SUIT 워드마크 SVG 패스를 그대로 씁니다. 태그라인은 디자인 시스템 서체 SUIT(`SUIT-Variable.woff2`, OFL) Medium 500입니다.
- 디자인 시스템은 앱 화면에 "튀어 오르는 스프링은 쓰지 않습니다"라고 정했지만, 이 로고 모션은 광고·릴스용이라 일부러 과장된 탄성을 썼습니다.
