# 팝업 로고 모션 (코드, 3.5초, 60fps, 4K)

AI 영상의 끊김, 모양 흔들림, 깨진 글자 없이 벡터로 그린 버전입니다. 공은 떨어지지 않고 제자리에서 팝업하며, 젤리처럼 출렁이지 않습니다. 끝 화면은 `reference-lockup-1280.png`(태그라인 "이웃과 나란히 걷는 산책")와 위치, 크기, 색이 같습니다.

## 움직임

| 시간 | 동작 | 이징 |
|---|---|---|
| 0.08–0.50s | 큰 원이 화면 가운데(최종 크기의 1.3배)에서 점으로부터 팝업 | 한 번 약 7% 넘치고 멈춤 |
| 0.22–0.62s | 작은 원 팝업 | 같음 |
| 0.45–0.89s | 길이 왼쪽 끝에서 오른쪽 끝까지 스와이프 | 빠른 출발, 부드러운 정지 |
| 0.89–1.06s | 쉼 | |
| 1.06 / 1.16 / 1.26s | 발가락 셋 팝업(왼쪽 · 위 · 오른쪽), 각 0.32초 | 한 번 넘치고 멈춤 |
| 1.60–2.30s | 마크가 1.3배에서 제 크기로 줄며 위로 이동 | ease-in-out |
| 2.08s / 2.20s | 워드마크, 이어서 태그라인이 36px 아래에서 올라오며 나타남(0.65초) | 디자인 시스템 ease-out-expo |
| 2.85–3.50s | 정지 | |

원은 끝까지 완벽한 원, 길은 일정한 굵기를 유지합니다. 크기와 위치만 움직입니다.

## 결과물 (`out/`)

모두 60fps, 3.5초, 무음입니다. `.png`는 4K 마지막 프레임입니다.

## 다시 만들기

```bash
./build.sh
```

- `render.js`: 타이밍, 이징, 시작 크기(1.3배)를 바꿉니다. 워드마크와 서체는 `../modudolbom-wordmark.svg`, `../SUIT-Variable.woff2`(디자인 시스템)를 씁니다.
- 레이아웃 수치는 `reference-lockup-1280.png`에서 잰 값입니다. 원본 이미지의 워드마크가 SVG보다 세로로 약 3% 낮아서 그 비율을 따랐습니다.
