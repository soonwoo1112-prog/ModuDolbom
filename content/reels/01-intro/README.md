# 01. 인스타 소개 릴스

18초, 9:16 (1080×1920). 빠른 컷 + 짧은 문장으로 "랜딩페이지를 영상으로" 푼 첫 소개 영상.

## 구성

| # | 화면 | 자막 |
|---|---|---|
| 1 | 빈 거실, 현관문을 바라보는 강아지 | 오늘도 혼자. |
| 2 | 벽시계 클로즈업 | 하루 9시간. / 아무도 없는 집 |
| 3 | 목줄을 문 강아지 | 산책, 하고 싶어. |
| 4 | 아파트 복도, 손 흔드는 이웃 | 옆집 이웃이 |
| 5 | 골든아워 단지 산책 | 대신 걸어줄게요. |
| 6 | 폰 지도 위 실시간 위치 | 지금 어디인지, / 실시간 GPS로 |
| 7 | 산책 사진을 보며 웃는 보호자 | 오늘의 산책, 전부 기록. / 사진 · 경로 · 배변까지 |
| 8 | 노을 속 달려오는 강아지 → 로고 | 모두돌봄 / 우리 동네 산책 이웃 |

## 제작

- 영상: Higgsfield Seedance 2.0 Mini (720p, 4초 × 8컷, 컷당 4크레딧)
- 음악: Higgsfield ElevenLabs Music v2.5 (인스트루멘털, 약 3크레딧)
- 자막·로고: `render.js` (Playwright + Pretendard)로 PNG 렌더
- 편집: `build.sh` (ffmpeg) — 컷 트림, 느린 줌인, 그레이딩, 자막 애니메이션, 로고 엔딩, 음량 정규화(-14 LUFS)
- 로고는 임시 심볼(집 + 발자국)입니다. 정식 로고가 나오면 `render.js`의 `logo`를 교체하세요.
