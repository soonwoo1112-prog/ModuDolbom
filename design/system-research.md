# 네 앱의 디자인 시스템 조사와 모두돌봄에 합칠 것 (2026-11-09)

토스, 당근, 애플, 크림의 디자인 시스템을 조사해 장점만 모은다. `design/direction.md`의 방향을 구체적인 규칙으로 바꾸는 문서다.

## 조사 범위와 확실한 정도

| 시스템 | 본 자료 | 확실한 정도 |
|---|---|---|
| 당근 SEED | seed-design.io 공식 문서와 토큰(`design/seed-reference.md`에 정리) | 공식 자료 |
| 애플 HIG | WWDC25 세션 소개, HIG 업데이트를 다룬 2차 자료 | 2차 자료. 세부 수치는 developer.apple.com에서 다시 확인 필요 |
| 토스 TDS | 공개 설명과 디자인 시스템 모음 사이트의 요약 | 2차 자료. TDS 공식 문서(developers-apps-in-toss.toss.im)는 이 작업 환경의 네트워크에서 막혀 읽지 못함 |
| 크림 | 디자인 시스템 모음 사이트의 요약, 앱 사용 기억 | 공개된 공식 디자인 시스템 없음. 가장 불확실 |

아래 "앱에서 확인한 특징"에서 공식 문서로 확인하지 못한 것은 앱을 써 본 일반적인 인상이다. 수치를 그대로 옮기지 않는다.

## 시스템별 장점

### 당근 SEED (공식)
- 색을 역할로 나눈다: 바탕·글자·선 × 중립·브랜드·위험·정보·긍정·경고 × 진함·옅음·눌림. 브랜드 색은 주 버튼과 선택에만.
- 4px 간격 단위, 화면 좌우 16px, 모서리 4~24px와 완전히 둥근 모양.
- 누르면 2px만큼 줄어드는 눌림 반응. 주변은 움직이지 않는다.
- 해요체, 익숙한 단어, 데이터가 아니라 사람의 행동으로 쓰는 글쓰기 규칙. 동네 이름을 넣어 쓴다.
- 목록 한 줄의 짜임(사진, 제목, 동네·시간, 가격)과 상태 배지.

### 애플 HIG (2차 자료)
- Liquid Glass는 내비게이션과 컨트롤에만 쓰고, 콘텐츠 뒤나 유리 위에 유리를 겹쳐 쓰지 않는다. 글자가 많은 곳은 덜 투명한 유리, 사진·영상 위는 더 투명한 유리.
- 글자는 왼쪽 정렬, 굵기를 높여 읽기 쉽게. 시스템 글자 크기 설정(Dynamic Type)을 따른다.
- 묶인 목록(설정 앱), 큰 제목, 바텀 시트, OS 기본 날짜·시간 선택기.

### 토스 TDS (2차 자료)
- 영문과 숫자는 자체 서체(Toss Product Sans), 한글은 Pretendard. 숫자 서체가 브랜드의 얼굴이 된다.
- 한 화면에 한 가지 일, 큰 제목, 화면 아래 고정 버튼 하나. 회색 단계를 촘촘히 써서 위계를 만든다.
- 단순함, 신뢰, 현대적인 느낌을 핵심으로 둔다.

### 크림 (가장 불확실)
- 거의 흑백인 화면에서 사진과 가격만 눈에 띈다. 검은 워드마크.
- 납작하고 촘촘한 목록, 장식 없는 날카로운 사진.
- 한글 Pretendard, 영문 애플 시스템 서체로 소개된다.

## 모두돌봄에 합칠 규칙

| 영역 | 규칙 | 어디서 |
|---|---|---|
| 색 | SEED식 역할 토큰은 그대로. 화면은 흰 바탕과 회색 단계가 95%, 숲색은 주 버튼·선택·지도 위 내 강아지에만 | SEED, 크림 |
| 서체 | 본문 한글은 읽기 편한 고딕 하나. 제목·숫자·로고에 모두돌봄만의 표시 서체 하나를 더해 얼굴을 만든다(아래 "서체") | 토스 |
| 위계 | 화면 제목 하나가 할 일을 말한다. 숫자(시간, 거리, 가격)는 본문보다 두 단계 크게 | 토스, 애플 |
| 간격·모서리 | 4px 단위, 좌우 16px, 모서리 12/16/24와 완전히 둥근 모양 | SEED |
| 재질 | 떠 있는 내비게이션(하단 탭)과 지도·사진 위 컨트롤만 유리. 카드와 시트는 불투명 | 애플 |
| 목록 | 한 줄 = 사진, 제목, 동네·시간, 굵은 가격. 설정은 묶인 목록 | 당근, 애플 |
| 사진 | 강아지 사진이 화면의 주인공. 사진 위 글자와 장식은 최소로 | 크림 |
| 움직임 | 상태가 바뀔 때만, 짧고 크게. 누름은 2px 줄임, 유리 렌즈는 살짝 튀며 자리 잡음. 동작 줄이기에서 멈춤 | SEED, 애플, 토스 |
| 글쓰기 | 해요체, 동네 이름, 사람의 행동, 한 문장 한 내용 | SEED |

## 서체

지금은 기기 기본 서체만 써서 앱에 얼굴이 없다. 토스처럼 본문은 한글 고딕 하나, 제목·숫자·로고에는 표시 서체 하나를 둔다. 후보(모두 자유롭게 쓸 수 있는 OFL)는 `서체와 로고 시안` 페이지에서 실제 화면 문구로 비교한다.

| 후보 | 인상 | 쓸 곳 |
|---|---|---|
| Pretendard | 토스·크림이 쓰는 표준 고딕. 중립적, 얼굴은 약함 | 본문 기준선 |
| SUIT | 기하학적이고 또렷함. 숫자가 단단함 | 제목·숫자 |
| Wanted Sans | 넓고 열린 형태, 매우 굵은 굵기까지 있음 | 제목·숫자·로고 |
| LINE Seed Sans KR | 둥근 기하 형태, 다정한 인상 | 제목·로고 |
| Hahmlet | 붓 맛이 남은 명조 계열, 따뜻하고 편집물 같음 | 로고·짧은 제목만 |

결정 후 DESIGN.md의 서체 항목과 토큰을 바꾼다.
