# TopNavigation

화면 위쪽의 SEED Top Navigation입니다. 높이는 `top-navigation`(56px)입니다.

- **Root, 로고와 동네(`md-topnav__location`)**: 보호자 예약 홈과 시터 오늘 탭. 왼쪽에 로고 마크 24px(`md-logo`), 그 옆에 동네 이름(18px Bold)과 아래 화살표. 누르면 동네를 바꿉니다. `aria-label`은 "동네 바꾸기, 지금 역삼동". 다크 테마에서 마크는 밝은 초록으로 올립니다.
- **Root, 글자 제목(`md-topnav__title`)**: 채팅, 캘린더, 더보기처럼 화면 이름이 곧 제목인 탭 첫 화면. 24px SUIT Bold, 왼쪽 정렬. 이때는 본문에 큰 화면 제목을 다시 두지 않습니다.
- **상단 바와 화면 제목을 겹치지 않기**: 바로 아래에 `screen-title`(26px SUIT Bold)이 오는 화면은 상단 바에 글자 제목 대신 로고와 동네를 둡니다.
- **Standard**: 2단계 이상 화면. 왼쪽에 뒤로 가기, 가운데에 제목(18px Bold). 오른쪽에 "조건 바꾸기" 같은 고스트 버튼이나 "⋯"를 둘 수 있어요.
  - **뒤로 가기는 실제로 온 화면으로 돌아갑니다.** 같은 강아지 프로필도 더보기에서 열면 더보기로, 채팅에서 열면 채팅으로 돌아갑니다. 링크에 적힌 목적지는 기록이 없을 때의 기본값입니다.
  - 완료 화면과 아래에서 올라온 화면은 뒤로 가기 대신 닫기를 씁니다.
- **아이콘 버튼**: 아이콘 24px, 누르는 영역 44px, `aria-label` 필수.
- **구분선**: 아래쪽에 1px `stroke-neutral-subtle` 선.
