# WalkLog

산책이 끝나면 남는 기록 카드입니다. 사진, GPS 경로, 강아지 상태를 한 장에 담습니다.

- 위쪽: 사진 슬롯(`md-slot`, 4:3)과 경로 지도(`md-route`). 경로선은 `blue` 4px, 출발점은 속 빈 원, 도착점은 채운 원입니다.
- 아래쪽: 제목(`title-2`), "산책 완료" 태그(`md-chip--done`), 숫자 세 개(`md-stats`: 산책 시간, 거리, 배변). 숫자는 `display` 서체, 단위는 `label`.
- 숫자는 기록된 값만 씁니다. 기록이 없으면 칸을 비우지 말고 "기록 없음".
- 소셜 피드에 올라간 공개 게시물에서는 생활 반경이 드러나지 않도록 경로 지도를 빼는 방안을 검토 중입니다(`docs/product/social.md`). 그때는 사진이 전체 폭을 씁니다.

미리보기의 경로와 숫자는 예시입니다.
