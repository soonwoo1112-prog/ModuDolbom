# WalkLog

산책이 끝나면 남는 기록 카드입니다. 사진, GPS 경로, 강아지 상태를 한 장에 담습니다.

- **위쪽**: 사진(SEED Image Frame, 4:3)과 경로 지도. 경로선은 `fg-informative` 4px, 출발점은 속이 빈 원, 도착점은 채운 원입니다. 사진이 없으면 발바닥 아이콘 자리를 둡니다.
- **아래쪽**: 제목(`section-title`), "산책완료" 배지, 숫자 세 개(`figure` 24/32 Bold, 단위는 t4 Medium).
- **숫자**: 기록된 값만 씁니다. 기록이 없으면 "기록 없음"으로 씁니다.
- **카드**: `r4`, 그림자 없이 1px `stroke-neutral-subtle` 테두리.
- **공개 게시물**: 생활 반경이 드러나지 않도록 경로 지도를 빼는 방안을 검토 중입니다. 그 경우 사진이 전체 폭을 씁니다.

미리보기의 경로와 숫자는 예시입니다.
