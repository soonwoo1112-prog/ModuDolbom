# SitterCard

모두돌봄을 대표하는 장면입니다. 보호자가 조건을 넣으면 3~10명의 후보가 나오고, 체크해서 **한 번에 요청**을 보냅니다.

카드에 들어가는 것(`docs/product/matching.md`의 검색 결과 표시 정보):
- 사진(`md-photo`, 64px, `radius-stock`). 사진이 없으면 `paper-3` 자리와 "사진".
- 이름(`title-2`), 가격(`body-strong`, 시터가 정한 값 그대로).
- 한 줄 소개(`ink-2`).
- 태그: 같은 아파트(`md-chip--apt`), 새로 온 시터(`md-chip--new`), 전담 시터.
- 사실 네 가지(`md-facts`, 정의 목록): 직선거리, 리뷰 수, 재이용 보호자 수, 평균 답장 시간. 리뷰가 없으면 0 대신 "아직 없어요".

상태: 선택하면 테두리가 2px `ink`가 됩니다(색 대신 굵기로도 구분). 카드 전체가 `label`이라 어디를 눌러도 체크됩니다.

요청 바(`md-requestbar`): 화면 아래에 고정되고, 선택한 수를 버튼 글자에 넣습니다("2명에게 요청 보내기"). 아무도 고르지 않았으면 비활성에 "시터를 한 명 이상 골라 주세요".

미리보기의 이름, 가격, 수치는 예시입니다. 실제 화면에는 시터가 입력한 값과 실제 집계만 씁니다.
