# TabBar

보호자와 시터가 쓰는 하단 탭 바입니다. 탭은 다섯 개로 고정합니다.

- 보호자: **예약**(첫 화면) / 채팅 / 소셜 / 캘린더 / 더보기
- 시터: **오늘**(첫 화면) / 채팅 / 소셜 / 캘린더 / 더보기

현재 탭은 `aria-current="page"`이고, `ink` 알약 채움에 `paper` 글자가 됩니다. 나머지는 `muted` 글자입니다. 바탕은 `paper-2`, 위쪽 1px `rule`. 높이 `tabbar`(64px)에 아래 안전 영역을 더합니다.

읽지 않은 수는 `md-badge`(`coral` 채움, 숫자)로 표시합니다. 숫자 없는 점은 쓰지 않습니다.

아이콘: 아이콘 체계가 정해지지 않아 지금은 글자 탭입니다. 아이콘을 넣을 때는 글자를 지우지 않고 아이콘을 위에 더합니다.
