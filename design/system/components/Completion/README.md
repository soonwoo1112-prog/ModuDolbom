# Completion

요청을 보낸 뒤처럼 한 일을 마친 순간의 완료 화면입니다.

- **구성**: 가운데에 초록 원 72px과 그 안에 그려지는 체크, 큰 제목("3명에게 요청을 보냈어요", 28px SUIT Bold), 누가 무엇을 받았는지 한 줄, "이제 일어나는 일" 두 줄(번호 원, `bg-layer-basement` 카드), 예약 요약 한 줄.
- **나가는 길**: 주 버튼은 **"홈으로 가기"**(Large, Brand). 시터가 답장하고 대화가 열리기까지 시간이 걸리므로 기다리게 하지 않고 홈으로 보냅니다. 그 아래 고스트 "보낸 요청 보기".
- 홈에 돌아가면 첫 카드에 "보낸 요청"이 남고, 누르면 요청 현황이 열립니다.
- 완료 화면에는 하단 탭과 뒤로 가기를 두지 않습니다.
- **움직임**: 원이 작게 시작해 제 크기로 자리 잡고(튀지 않음), 체크가 한 번 그려집니다. 동작 줄이기에서는 그려진 상태로 바로 보여 줍니다.
- 산책이 끝난 보호자 화면처럼 축하가 어울리는 곳에서도 같은 구성을 씁니다. 장식이나 색종이를 더하지 않습니다.
