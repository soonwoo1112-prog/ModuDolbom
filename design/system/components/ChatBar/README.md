# ChatBar

채팅 화면 위쪽의 예약 바입니다. 보호자 채팅과 시터 채팅이 같은 모양을 씁니다.

- **첫 줄**: 강아지 사진 40px(누르면 강아지 프로필), 예약 한 줄("보리, 11월 7일 (토) 오후 12:30", 17px 이하 SUIT Bold)과 그 아래 "30분 산책, 15,000원", 확정 뒤에는 "확정" 배지, 오른쪽 "⋯"(전화 걸기는 안심번호, 고객센터, 신고하기, 취소하기).
- **둘째 줄**: 같은 크기의 알약 버튼 세 개(`cb__btn`, 36px). 너무 크고 무거웠던 버튼을 대신합니다.
  - 보호자: "예약 확정"(초록, `cb__btn--brand`) / "수정" / "정보". 확정하면 첫 알약이 비활성 "확정했어요"로 바뀝니다.
  - 시터: "확정 기다리는 중" 또는 "확정됐어요"(비활성) / "수정" / "정보".
  - "수정"은 날짜(달력), 시간(휠), 수정 이유를 받는 페이지, "정보"는 강아지, 시작과 끝, 비용, 주소, 보험 안내를 보여 주는 시트입니다.
- 바탕은 `bg-layer-basement`, 아래 1px 선. 취소처럼 되돌릴 수 없는 행동은 "⋯" 안에 두고 확인 창을 띄웁니다.
