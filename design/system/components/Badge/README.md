# Badge

대상의 속성이나 상태를 보여 주는 작은 레이블입니다. SEED Badge Large(24px, `r1_5`, t2)입니다. 누를 수 있는 요소로 쓰지 않습니다.

- `md-badge--brand`: **같은 아파트**. 거주지 인증으로 같은 단지가 확인된 시터에게만. 모두돌봄의 대표 신호라서 브랜드 색을 씁니다.
- `md-badge`(Neutral Weak): 새로 온 시터, 성격 태그.
- `md-badge--outline`: 전담 시터.
- `md-badge--brand-solid`: 확정. 상태값이라 붙여 씁니다.
- `md-badge--critical`: 급해요. 화면에 한 곳만.
- `md-badge--info`: 대화중, 요청중 같은 진행 상태.
- 한 행에 배지는 두 개까지. 그 이상 정보는 목록의 보조 정보(`md-tags`)로 씁니다.
