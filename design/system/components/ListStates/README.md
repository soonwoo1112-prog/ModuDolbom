# ListStates

데이터를 불러오는 모든 영역은 네 가지 상태를 가집니다: **불러오는 중, 비어 있음, 오류, 채워짐**. 이 카드는 앞의 세 가지입니다.

- **불러오는 중**: 올 내용의 모양을 본뜬 `paper-3` 스켈레톤(`md-skel`). 영역에 `aria-busy="true"`. 깜빡이는 효과는 쓰지 않습니다.
- **비어 있음**: 여기에 무엇이 올지 한 문장, 그리고 그걸 채우는 행동 하나(`md-state` + 기본 버튼).
- **오류**: 무엇이 안 됐는지와 어떻게 하면 되는지. `role="alert"`, 보조 버튼 "다시 시도". 사과나 막연한 문장은 쓰지 않습니다.

제목은 `title-2`, 설명은 `body`.
