# Feedback

화면 안에 남는 안내(Callout)와 잠깐 나타나는 결과 알림(Snackbar)입니다.

- **Callout(`md-callout`)**
  - 쓰는 곳: 채팅의 예약 정보 시트에 "앱에서 예약한 산책만 보험으로 보장돼요". 앱 밖 직거래를 막는 핵심 안내라서 예약을 확인할 때 보이게 합니다.
  - 톤: Informative가 기본이고, 주의가 필요하면 `--warning`, 문제가 생기면 `--critical`을 씁니다.
  - 아이콘은 채움형 대신 18px 선형 info를 씁니다. 제목은 굵게 한 줄, 설명은 한두 문장.
- **Snackbar(`md-snackbar`)**
  - 쓰는 곳: 행동의 결과("요청을 보냈어요", "요청을 거절했어요").
  - `bg-neutral-solid`, 모서리 `r2`, 최소 높이 44px. 하단 탭 위에 뜨고 4초 뒤 사라집니다. 계속 남아 있지 않습니다.
  - 되돌릴 수 있는 행동에는 "되돌리기"를 붙입니다. 확인 창보다 이쪽을 먼저 씁니다.
  - 되돌릴 수 없는 행동(요청 모두 취소, 예약 취소)을 스낵바 안에 두지 않습니다. 화면 안 고스트 버튼으로 두고 확인 창을 거칩니다.
- **확인 창(Alert Dialog)**: 되돌릴 수 없을 때만. 제목은 질문("요청을 모두 취소할까요"), 무엇이 사라지는지 한두 문장, 왼쪽 "닫기", 오른쪽 Critical 버튼.
- **완료 화면**: 큰 일을 마친 순간은 스낵바 대신 완료 화면을 씁니다(`Completion`).
