# SitterList

모두돌봄의 대표 장면입니다. 보호자가 조건을 넣으면 3~10명의 후보가 SEED List로 나오고, 체크해서 **한 번에 요청**을 보냅니다.

- **행 구성(List Item, Align Top)**
  - 왼쪽(Prefix): 아바타 48px(`avatar-list`). 사진이 없으면 사람 아이콘의 대체 이미지.
  - 가운데: 이름(`list-title`)과 배지, 한 줄 소개(`fg-neutral-muted`), 보조 정보(`md-tags`, t3 `fg-neutral-subtle`).
  - 오른쪽(Suffix): 체크박스. 선택되면 행 바탕이 `bg-brand-weak`가 됩니다.
- **보조 정보**: 두 줄로 씁니다. 첫 줄은 가격(굵게)과 직선거리, 둘째 줄은 리뷰 수, 재이용 보호자 수, 평균 답장. 리뷰가 없으면 0 대신 "리뷰 아직 없음".
- **배지**: 같은 아파트(`md-badge--brand`), 새로 온 시터, 전담 시터. 한 행에 두 개까지.
- **목록 순서**: 거리, 리뷰, 가격을 종합해 서로 다른 강점을 가진 시터가 섞이게 하고, 새로 온 시터 1~2명을 항상 포함합니다.
- **요청 바**: 화면 아래 고정. 선택한 수를 버튼 글자에 넣습니다("2명에게 요청 보내기"). 아무도 고르지 않았으면 비활성으로 두고 "시터를 한 명 이상 골라 주세요"라고 안내합니다.
- **누름**: 행 전체가 누를 수 있는 영역이고, 누르는 동안 0.979배로 줄어듭니다(폭 375px 기준).

미리보기의 이름, 가격, 수치는 예시입니다.
