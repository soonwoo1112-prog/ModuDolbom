# SitterList

시터 고르기 화면입니다. 예약 단계에서 고른 조건에 맞는 시터가 나오고, 여러 명을 골라 **한 번에 요청**을 보냅니다.

- **맨 위**: 화면 제목 "누구에게 요청할까요"와 고른 조건을 알약 칩 줄로(강아지, 날짜와 시간, 길이). 오른쪽 위 "조건 바꾸기"는 예약 단계로 돌아갑니다.
- **행 구성**
  - 왼쪽: 사진이나 이니셜 원 56px(`avatar-card`). **사진을 누르면 프로필**이 열립니다.
  - 가운데: 이름(`list-title`)과 배지, 한 줄 소개, 가격, 보조 정보.
  - 오른쪽: 원형 체크 28px. **사진을 뺀 줄 나머지 어디를 눌러도 고르기**입니다. 한 줄에 누를 곳이 겹치지 않게 이름에는 링크를 걸지 않습니다.
  - 고른 줄은 `bg-neutral-weak` 면과 초록 체크. 줄 전체를 초록으로 칠하지 않습니다.
- **가격**: 그 조건의 한 번 가격을 `price` 스타일로 크게. 옆에 "2마리, 60분, 한 번"처럼 무엇의 가격인지. 여러 번이면 아래 줄에 "3번 모두 99,000원". 계산은 시터 프로필 가격표대로입니다(60분은 30분 가격의 1.7배, 한 마리 더하면 30분 가격의 절반). 가격표에 없는 길이(90분)는 "대화에서 정해요"로 쓰고 값을 지어내지 않습니다.
- **보조 정보**: 별점과 후기 수(별은 `fg-rating`), 거리, 평균 답장. 후기가 없으면 "후기 아직 없음".
- **배지**: 같은 아파트(`md-badge--brand`), 새로 온 시터. 한 줄에 두 개까지. 새로 온 시터 1~2명을 늘 목록에 넣습니다.
- **요청 바**: 화면 아래 고정. "2명에게 요청 보내기". 아무도 고르지 않았으면 비활성 "시터를 눌러서 골라 주세요". 위에 "한 명과 확정되면 나머지 요청은 자동으로 닫혀요".

미리보기의 이름, 가격, 수치는 예시입니다.
