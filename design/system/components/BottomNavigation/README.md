# BottomNavigation

탭 첫 화면 아래에 떠 있는 하단 탭입니다. 탭은 다섯 개로 고정합니다.

- **보호자**: 예약(첫 화면) / 채팅 / 소셜 / 캘린더 / 더보기
- **시터**: 오늘(첫 화면) / 채팅 / 소셜 / 캘린더 / 더보기
- **모양**: 화면 좌우와 아래에서 16px 떨어져 뜬 유리 알약(높이 64px, `full`). 뒤 내용이 흐릿하게 비치고 위쪽에 얇은 빛 테두리가 있습니다. 다크 테마에서는 짙은 유리로 바뀝니다. 유리는 이 탭 바와 사진·지도 위 버튼에만 씁니다.
- **선택 상태**: 지금 탭(`aria-current="page"`) 아래에 밝은 렌즈가 놓이고, 아이콘과 레이블이 `fg-brand`에 굵게 바뀝니다. 렌즈는 화면이 열릴 때 튀지 않고 부드럽게 자리 잡습니다. 누르는 동안 렌즈가 살짝 커지고 아이콘은 살짝 작아집니다.
- **구성**: 아이콘 24px(Lucide)과 레이블 11px. 레이블은 두세 글자.
- **안 읽은 수**: `md-nbadge`(`bg-critical-solid`, 숫자). 숫자 없는 점은 쓰지 않습니다.
- **아래 내용**: 탭 바 뒤로 스크롤되는 내용은 화면 끝에서 흐리게 사라지게 하고(`md-fade-under`), 목록 끝에는 탭 바만큼(96px) 여백을 둡니다. 화면 아래 고정 버튼이 있는 화면은 그 버튼이 흐려지지 않게 흐림을 빼요.
- **링크**: 다섯 탭은 모든 화면에서 같은 곳으로 갑니다. 누를 수 없는 탭을 두지 않습니다.
