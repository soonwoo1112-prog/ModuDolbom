# BookingGroup

채팅 목록을 예약별로 묶는 방식입니다. 한 번에 여러 날짜, 여러 시터에게 요청하므로 대화만 늘어놓으면 어떤 예약의 대화인지 알 수 없기 때문입니다.

- **순서**: 가까운 날짜의 예약부터. 시터 쪽은 끝난 산책을 "끝난 산책" 머리글 아래 맨 뒤에 둡니다.
- **예약 카드(`cl-booking`)**: 강아지 사진(두 마리면 겹친 원 두 개), "보리, 콩이 산책", 날짜와 횟수와 시간("11월 9일, 10일, 11일, 3번, 오후 12:30"), 길이와 만나는 곳, 상태 배지(확정 / 답장 기다리는 중 / 새 요청 / 끝남). 확정된 예약은 예약 정보로, 답장을 기다리는 예약은 요청 현황으로 갑니다.
- **대화 줄(`cl-chat`)**: 카드 아래에 그 예약으로 열린 대화를 들여 써서 둡니다. 이름, 상태 배지(확정한 시터, 대화 중, 답장 기다리는 중, 요청 닫힘), 마지막 메시지, 시간, 안 읽은 수.
- 확정으로 닫힌 요청과 끝난 산책은 흐리게(불투명도 0.6) 둡니다.
- 예약 묶음 사이는 8px `bg-layer-basement` 띠.
- **요청 현황**: 답장을 기다리는 예약을 누르면 열리는 화면도 같은 예약 카드를 맨 위에 두고, 요청한 시터마다 줄 하나(누르면 대화)를 둡니다. 줄마다 버튼을 두지 않습니다. 아래에 "다른 시터에게도 요청하기"(Outline)와 고스트 "요청 모두 취소하기"(확인 창).
