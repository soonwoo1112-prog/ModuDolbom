# RequestCard

시터의 **오늘** 탭 구성입니다. 위에는 새 요청, 아래에는 오늘 예약이 List로 나옵니다.

- **새 요청**: 강아지 사진, 이름과 크기 배지, 날짜·시간·길이·만날 장소 한 줄, 받은 시간.
  - 행동은 "대화창 열기"(Neutral Solid)와 "거절"(Neutral Weak) 두 개입니다. 시터가 바로 확정하지 않고 대화로 맞춘 뒤 확정합니다.
  - 급한 요청에는 `md-badge--critical` "급해요"를 붙입니다.
- **오늘 예약**: 행 오른쪽에 "산책 시작"(Brand Solid, Small)을 둡니다. 누르면 GPS 기록이 시작되고, 버튼이 "산책중"으로 바뀝니다.
- 두 묶음 사이는 8px `bg-layer-basement` 띠로 나눕니다.
- 거절은 확인 창 없이 바로 처리하고, 스낵바로 "거절했어요"와 "되돌리기"를 보여 줍니다.
