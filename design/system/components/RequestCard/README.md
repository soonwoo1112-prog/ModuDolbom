# RequestCard

시터의 **오늘** 탭과 새 요청 자세히 화면입니다. 위에는 새 요청, 아래에는 끝난 산책과 오늘 예약이 나옵니다.

- **새 요청 줄**: 강아지 사진, 이름과 크기·"같은 아파트" 배지, 날짜·시간·길이·만날 장소 한 줄, 받은 시간과 보호자.
  - 행동은 알약 버튼 두 개 "대화하기"(말풍선 아이콘)와 "거절". 같은 무게라서 둘 다 흰 알약입니다. 시터는 바로 확정하지 않고 대화로 맞춘 뒤, 보호자와 시터가 둘 다 확정해야 예약이 완료됩니다.
  - 급한 요청에는 `md-badge--critical` "급해요".
- **새 요청 자세히**: 강아지 사진을 크게, 요청 내용(날짜, 시간, 만나는 곳, 받는 금액)과 "정확한 동·호수와 픽업 안내는 보호자가 예약을 확정하면 보여요". 아래에 Large 주 버튼 "보리네 보호자와 대화하기" 하나, 그 아래 작게 고스트 "이 요청 거절하기".
- **오늘 예약 줄**: 오른쪽에 "산책 시작"(Brand, Small). 누르면 산책 기록이 시작됩니다. 화면의 초록은 이 버튼 하나입니다.
- 묶음 사이는 8px `bg-layer-basement` 띠.
- 거절은 확인 창 없이 처리하고, 스낵바 "요청을 거절했어요"와 "되돌리기"를 몇 초 보여 줍니다.
