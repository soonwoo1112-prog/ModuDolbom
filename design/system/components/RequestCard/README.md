# RequestCard

시터의 **오늘** 탭 맨 위에 뜨는 새 요청입니다. 시터는 바로 확정하지 않고 **대화창 열기** 또는 **거절**을 고릅니다.

- 머리: `md-chip--loud` "새 요청"과 받은 시간. `coral`은 이 카드에만 씁니다.
- 내용: 강아지 사진과 이름·크기(`title-2`), 날짜·시간·길이·만날 장소(`label`). 한 줄 문장으로, 가운뎃점으로 잇지 않습니다.
- 행동: 대화창 열기(기본, 2/3 폭)와 거절(보조, 1/3 폭).
- 떠 있는 카드라 `shadow-card`를 씁니다.

거절을 누르면 바로 사라지지 않고 "거절했어요. 되돌리기"를 몇 초 보여 줍니다.

같은 자리에서 오늘 예약 카드의 주요 버튼은 "산책 시작"(`md-btn--primary md-btn--lg`)이고, 누르면 GPS 기록이 시작됩니다.
