# BookingInputs

예약 화면에서 날짜, 주소, 픽업 안내를 받는 입력 묶음입니다. SEED Segmented Control, Input Button, Bottom Sheet, Date Picker로 만듭니다.

- **횟수(`md-seg`)**: 날짜 위에 "한 번 / 반복" Segmented Control을 둡니다. 선택된 항목은 흰 면에 굵은 글자입니다. 날짜 시트 안에도 같은 컨트롤을 둬서 시트에서 바로 바꿀 수 있어요.
- **날짜(`md-inputbtn`)**: 누르면 아래에서 날짜 시트가 올라옵니다. 버튼에는 고른 결과를 씁니다.
  - 한 번: "11월 7일 (토)"
  - 반복: "매주 월, 수, 금", 아래 줄에 "11월 9일부터 30일까지, 모두 10번" 또는 "11월 9일부터 계속"
- **날짜 시트, 한 번**: 달력에서 하루를 고릅니다. 고른 날은 `bg-brand-solid` 원, 오늘은 테두리 원, 지난 날은 `fg-disabled`로 누를 수 없어요.
- **날짜 시트, 반복**
  - 산책하는 요일을 칩으로 여러 개 고릅니다.
  - 달력에서 시작하는 날과 끝나는 날을 차례로 누르면, 호텔 예약처럼 그 사이가 `bg-brand-weak` 띠로 이어집니다. 양 끝은 `bg-brand-solid` 원입니다.
  - 기간 안에서 산책하는 날은 `fg-brand` 굵은 숫자와 아래 점으로 표시합니다.
  - "끝나는 날 없이 계속하기"를 켜면 시작하는 날만 고릅니다.
  - 시트 아래에 결과를 한 문장으로 보여 줍니다("11월 9일부터 30일까지 매주 월, 수, 금, 모두 10번 산책해요"). 요일이나 끝나는 날이 비어 있으면 확인 버튼을 비활성으로 두고 무엇이 빠졌는지 버튼 글자로 알려 줍니다.
- **주소(`md-inputbtn`)**: 지금 쓰는 주소의 이름(굵게), 도로명과 상세 주소, 들어오는 방법을 세 줄로 보여 줍니다. 누르면 주소 목록 시트가 올라옵니다.
- **주소 목록 시트**: 저장된 주소들과 "주소 추가하기". 지금 쓰는 주소에는 "지금 쓰는 주소" 배지. 주소를 누르면 자세히 시트로 넘어갑니다.
- **주소 자세히 시트**: 상세 주소, 이름(집, 회사, 부모님 댁, 기타), 들어오는 방법(비밀번호, 호출, 열려 있어요). 비밀번호나 호출을 고르면 번호 입력칸이 나오고 "예약이 확정된 시터에게만, 산책 당일에 보여요"라고 알려 줍니다. 버튼은 "저장하고 이 주소 쓰기".
- **픽업 안내(`textarea.md-input`)**: 주소 아래 선택 입력. 시터가 들어오고 강아지를 데리고 나가는 방법을 적습니다. 아래 Outline 칩(자주 쓰는 안내)을 누르면 문장이 이어 붙습니다. 300자까지, 글자 수를 보여 줍니다.
- 시트는 하단 탭까지 덮고(`md-overlay`), 바깥을 누르거나 닫기를 누르면 닫힙니다.
