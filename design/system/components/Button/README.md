# Button

주요 행동은 `pear` 카드 스톡 버튼 하나, 나머지는 `card` 보조 버튼이나 텍스트 버튼입니다.

- **기본(`md-btn--primary`)**: 화면에서 가장 중요한 행동 하나에만 씁니다. 예약 화면의 "요청 보내기", 오늘 탭의 "산책 시작". 한 화면에 하나.
- **크게(`md-btn--lg`)**: 화면 아래에 고정되는 주요 버튼. 높이 `control-lg`(54px), 폭 100%.
- **보조(`md-btn`)**: `card` 면에 `rule` 테두리, 아래 5px `edge` 두께선.
- **텍스트(`md-btn--text`)**: `blue` 밑줄 글자. 조건 바꾸기, 더 보기 같은 가벼운 이동.
- **비활성**: `disabled` 또는 `aria-disabled="true"`. 왜 누를 수 없는지 근처에 한 줄로 적습니다("요청이 이미 마감됐어요").
- **처리 중**: `aria-busy="true"`와 함께 글자를 "보내는 중"으로 바꿉니다.

동작: 마우스를 올리면 두께선이 7px로 올라오고, 누르면 1px로 눌립니다. 스프링 곡선은 기본 버튼에만 씁니다. 동작 줄이기 설정에서는 움직이지 않습니다.

글자: 동사로 끝나는 짧은 해요체 명령형("요청 보내기", "산책 시작"). 느낌표 없이.

소비자가 줄 것: 버튼 글자, `type`, 상태 속성. 아이콘은 아직 정해지지 않았으니 넣지 않습니다.
