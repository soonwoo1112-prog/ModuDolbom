# 모두돌봄 로고

나란히 걷기: 이웃(큰 원)과 강아지 발바닥(작은 원과 발가락 셋)이 웃는 길 위를 함께 걷는 마크. Rikyu AI로 만든 시안(2026-11-09)을 원 5개와 호 1개로 다시 그렸다(원본과 겹치는 면적 98%). 그리는 식은 `../mark.py`.

| 파일 | 쓰는 곳 |
|---|---|
| `mark.svg`, `mark-white.svg`, `mark-ink.svg` | 마크만. 숲색, 어두운 바탕용 흰색, 한 가지 색만 될 때 잉크 |
| `lockup.svg`, `lockup-white.svg` | 마크와 글자. 글자는 SUIT ExtraBold(OFL)를 윤곽선으로 바꾼 것이라 서체 파일 없이 쓴다 |
| `wordmark.svg` | 글자만 |
| `app-icon.svg`, `app-icon-512.png` | 모서리가 둥근 앱 아이콘(미리보기, 웹) |
| `app-icon-square.svg`, `app-icon-square-1024/512/180/120.png` | 스토어 제출용. 모서리는 OS가 둥글게 깎는다 |
| `app-icon-light.svg` | 흰 바탕 아이콘 |
| `favicon.svg` | 브라우저 탭 |

규칙
- 여백: 마크 둘레에 작은 원 지름만큼.
- 최소 크기: 마크 너비 16px, 글자와 붙인 로고 높이 20px.
- 색: 숲색 #00733A 또는 흰색 한 가지. 그라데이션, 그림자 없음.
- 하지 않을 것: 원의 크기 비율 바꾸기, 길 뒤집기(우는 얼굴), 돌리기, 늘리기.

## 세로형 로고 (마크, 이름, 슬로건)

캔버스의 "브랜드: 세로형 로고" 줄에 있는 `LogoStack` 보드(`design/canvas/LogoStack.dc.html`)에서 만들어요. Tweaks에서 마크 크기, 이름과 슬로건 크기, 마크와 이름 사이·이름과 슬로건 사이 간격, 이름 굵기(700/800), 자간, 색 조합(초록 마크와 검은 글자, 모두 초록, 초록 바탕에 흰색, 다크 바탕)을 바꿀 수 있어요. "모두돌봄"과 슬로건 글자는 보드에서 바로 고쳐 써요. 슬로건 "이웃과 나란히 걷는 산책"은 초안이에요.
