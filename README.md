# 모두돌봄 (ModuDolbom)

**우리 동네 이웃이 내 강아지를 산책시켜 주는 앱.**
같은 동네, 같은 아파트에 사는 사람들끼리 반려견 산책을 맡기고 맡는 중개 플랫폼.

> 현재 기획 단계입니다. 아래 내용은 논의 중인 방향이며 확정된 사양이 아닙니다.

## 1. 배경

### 돌볼 사람이 줄고 있다

- 서울의 반려견 등록 수는 올해 잠시 줄었지만, 그 전까지는 꾸준히 늘어 왔다. 현재 약 61만 마리가 서울에 등록되어 있다.
- 1인 가구 비율도 계속 늘고 있다.
- 그 결과, 보호자가 집을 비울 때 강아지를 대신 봐줄 가족이 없거나, 혼자 모든 돌봄을 감당해야 하는 부담이 커지고 있다.

### 인식은 좋아졌지만 현실은 아직 멀다

- 반려견을 키우는 사람이 늘면서 책임감 있게 키우려는 인식도 함께 좋아지고 있다.
- 하지만 실제로는 산책을 제대로 못 하거나, 보호자가 출근한 낮 동안 오랜 시간 혼자 남겨지는 강아지가 많다.
- "강아지는 매일 밖에 나가 산책해야 한다"는 인식이 더 퍼질 필요가 있다.

## 2. 지금의 대안과 한계

| 대안 | 장점 | 한계 |
|---|---|---|
| 가족(부모님, 형제)이나 친구에게 부탁 | 믿을 수 있음 | 자주 부탁하면 서로 부담이 됨 |
| 강아지 유치원, 호텔 등 돌봄 시설 | 전문 시설 | 직접 데려다주고 데려와야 하고, 비용이 비쌈 |
| 기존 돌봄·산책 앱 | 가격이 적당함 | 모르는 사람에게 맡기는 것에 대한 불신이 큼. 마케팅이 약해 잘 알려지지 않음 |

정리하면, **자주 맡기기엔 부담스럽고, 모르는 사람에게 맡기기엔 믿음이 안 가고, 시설에 맡기기엔 멀고 비싸다.**
모두돌봄은 이 세 가지 문제를 한 번에 푸는 것을 목표로 한다.

## 3. 핵심 아이디어: 동네라서 믿을 수 있다

### 당근마켓에서 얻은 힌트

중고거래 시장은 번개장터가 먼저 자리 잡고 있었지만, 사기나 택배 거래 같은 문제가 있었다. 당근마켓은 같은 물건을 거래하면서도 **"같은 동네, 비슷한 생활 반경을 가진 사람과 익숙한 동네에서 거래한다"** 는 아이디어 하나로 수많은 사용자를 모았다. 동네에서 한 번쯤 마주쳤을 법한 사람과 만난다는 안심, 그리고 따뜻하고 편한 화면이 같은 서비스를 훨씬 활발하게 만들었다.

모두돌봄은 이 아이디어를 반려견 돌봄에 가져온다. 서울처럼 좁은 지역에 61만 마리의 반려견이 모여 사는 도시는 동네 단위 매칭에 특히 잘 맞는다.

- **보호자:** 같은 동네, 같은 아파트나 이웃 아파트에 사는, 비슷한 환경과 생각을 가진 사람에게 믿고 맡길 수 있다.
- **시터:** 동네에 사는 누구나 시터가 될 수 있다.

### 경쟁사와의 차이: 에이전트가 아니라 중개

| | 기존 경쟁사 | 모두돌봄 |
|---|---|---|
| 신뢰를 만드는 방식 | 신원 조회, 시터를 직접 고용해 관리 | 같은 동네라는 친밀감, 인증, 리뷰, 보험 |
| 시터의 지위 | 고용된 직원에 가까움 | 프리랜서 |
| 가격 | 회사가 정한 고정 가격 | 시터가 직접 정함 |
| 성격 | 산책 대행 회사(에이전트) | 이웃을 연결하는 중개 플랫폼 |

### 누구나 시터가 될 수 있다

시터가 되는 문턱을 낮추면(물론 아무나 받지는 않는다), 앱을 접하는 모든 사람이 보호자든 시터든 잠재 고객이 된다.

- 점심시간이 한가한 주부
- 아침에 일찍 일어나는데 딱히 할 일이 없는 사람
- 수업 없는 날 강아지와 놀고 싶은 대학생

> **창업자의 경험:** 강아지를 정말 좋아하지만, 길 가는 사람을 붙잡고 강아지를 만질 수도 없고, 강아지 없이 애견 카페에 가기도 부담스러웠다. 지금은 산책 시터로 일하면서 원 없이 강아지와 놀고 돈도 벌고 있다. 이런 사람은 생각보다 많다.

## 4. 차별화 기능

### 4-1. 매칭: 골라진 후보에게 한 번에 요청

**문제: Rover의 검색**

북미에서 수천억 원의 매출을 내는 Rover도 검색에는 불편한 점이 많다.

- **보호자 입장:** 날짜, 강아지 무게, 위치를 넣고 검색하면, 바쁜 도시에서는 수백 명의 시터가 뚜렷한 기준 없이 나열된다. 가격순, 리뷰순, 거리순 정렬도 없다. 누구는 리뷰가 가장 좋은 시터를, 누구는 가장 저렴한 시터를 원하지만, 결국 수십 명을 직접 내려보며 하나씩 확인하고 메시지를 보내야 한다. 매칭이 안 되면 예약 메뉴를 다시 열어 같은 과정을 반복한다.
- **시터 입장:** 순서가 불분명하다 보니 어차피 받을 수 없는 먼 거리의 요청이 오고, 리뷰가 적거나 없는 시터는 수십 번째, 백 번째 이후로 밀려 요청 하나 받기도 어렵다.

**해결: 모두돌봄의 예약 흐름**

1. 보호자가 조건을 입력하면, 거리·리뷰·가격을 종합해 가장 잘 맞는 시터 **3~10명**이 뜬다.
2. 보호자는 그중 원하는 시터 여러 명을 체크해서 **한 번에 요청**을 보낸다.
3. 요청을 받은 시터 중 가능한 사람은 **수락**을 누르고, 그러면 대화창이 열린다.
4. 보호자는 대화창이 열린 시터들과 이야기를 나눈다.
5. 한 시터와 확정하면, 나머지 요청과 대화는 **자동으로 회수**된다. "다른 시터 구했어요"를 일일이 보낼 필요가 없다.

**후보 구성 규칙**

- **신규 시터 1~2명은 항상 포함**한다. 새로 들어온 시터가 가격을 내리지 않고도 자리를 잡을 수 있게 하기 위해서다.
- **전담시터(가칭):** 한 번 예약한 시터를 전담시터로 지정하면, 이후 검색에 항상 포함된다.
- **급한 예약:** 후보 범위를 더 넓히고, 평균 답장 시간이 빠르고 수락률이 높은 시터를 우선 포함한다.

**검색 결과에 보이는 정보**

- 사진, 이름, 한 줄 소개
- 가격
- 보호자 위치와의 직선거리
- 리뷰 수, 재이용 고객 수
- 평균 답장 시간
- "같은 아파트" 태그 (해당되는 경우)

### 4-2. 동네 소셜: 산책 로그와 커뮤니티

모두돌봄은 예약 앱에 그치지 않고, 동네 애견인들이 모이는 공간이 된다. 소셜 페이지는 두 공간으로 나뉜다.

**① 산책 로그·사진 피드**

- 산책 기록, 강아지 사진, 짧은 글을 올리는 SNS 형식의 피드.
- 길을 걷다 피드에서만 보던 강아지를 실제로 만나 말을 걸게 되는, 정겨운 동네 생활을 만든다.
- 시터에게는 자신을 알리는 홍보 수단이 된다. 사진을 잘 찍는다거나 산책 루트가 좋다는 점을 보여주며 프로필을 꾸밀 수 있다.
- **게시글에서 시터 프로필로 들어가 바로 예약**할 수 있다.

**② 동네 커뮤니티**

- 강아지를 잃어버렸을 때, 용품을 나누거나 추천할 때, 주변 애견 동반 카페 같은 정보를 공유하는 게시판.

**앱에 머물 이유 만들기**

- 좋아요 수로 "인기 강아지", "인기 시터"를 선정해, 보호자와 시터 모두에게 앱에 남을 이유를 준다.

**누가 무엇을 올릴 수 있나**

| | 보호자 | 시터 |
|---|---|---|
| 산책 로그 | 자기 강아지의 산책 로그 게시 | 산책을 마친 뒤 게시. 보호자가 공유를 허용한 경우에만 가능 |
| 사진·글 | 게시 가능 | 산책 로그만 게시 |
| 커뮤니티 | 글 작성, 댓글 | 댓글 |
| 피드 활동 | 보기, 좋아요, 댓글 | 보기, 좋아요, 댓글, 내 로그 모아보기 |

> 공개 게시물에서는 산책 경로 지도를 빼는 방안을 검토 중이다. 강아지와 보호자의 생활 반경이 드러날 수 있기 때문이다.

### 4-3. 산책 부가 기능

- **AI 추천 산책 경로:** 시터의 출발 지점을 기준으로 산책 경로를 추천한다.
- **실시간 GPS:** 정확한 위치 추적으로, 보호자가 산책 중인 강아지가 지금 어디 있는지 확인할 수 있다.
- **산책 로그:** 산책이 끝나면 사진, GPS로 기록된 경로, 배변 횟수 등을 남긴다.

## 5. 앱 구성

보호자와 시터는 서로 다른 화면을 쓰고, 둘 다 하단 탭 바로 이동한다.

### 보호자 화면

| 탭 | 내용 |
|---|---|
| **예약** (첫 화면) | 예약 조건을 직관적으로 입력하고 바로 요청을 보내는 화면. 딱딱하지 않고 친근한 느낌으로 만든다. |
| **채팅** | 요청으로 열린 대화 목록. 대화 안에서 요청 내용(세부 사항)을 확인하고 수정할 수 있다. |
| **소셜** | 산책 로그·사진 피드와 동네 커뮤니티 ([4-2](#4-2-동네-소셜-산책-로그와-커뮤니티) 참고). |
| **캘린더** | 확정된 예약을 날짜에 하이라이트로 표시한다. |
| **더보기** | 프로필·프로필 설정, 강아지 정보·수정, 결제, 분석, 고객 지원, 설정 등. |

### 시터 화면

| 탭 | 내용 |
|---|---|
| **오늘** (첫 화면) | 새로 들어온 요청이 맨 위에 뜬다. 눌러서 세부 내용을 보고 수락하거나 거절한다. 그 아래에 오늘 예약 목록이 있고, **한 번 터치로 산책 시작**(GPS 기록 시작)을 할 수 있다. |
| **채팅** | 보호자 채팅과 비슷하며, 예약 확정, 수정, 세부 사항 확인이 가능하다. 대화를 확정, 대기 중, 진행 중, 지난 대화, 안 읽음, 보관함으로 나눠 볼 수 있다. |
| **소셜** | 보호자 화면과 비슷하지만, 산책을 마친 뒤 산책 로그만 올릴 수 있다. 피드를 보고 좋아요와 댓글을 남기고, 내 로그를 한곳에서 모아 본다. |
| **캘린더** | 여러 강아지를 맡으므로 날짜마다 강아지 사진이 들어간 하이라이트로 표시한다. 날짜를 누르면 그날의 예약 목록이 나온다. 일할 수 있는 날짜와 시간대를 켜고 끄거나 수정한다. |
| **더보기** | 서비스 설정, 결제, 분석, 프로필, 고객 지원, 설정 등. |

## 6. 운영 원칙

### 보험: 앱 안에서 예약한 건만 보장

- 펫보험사와 제휴해, **시터로 가입할 때 보험에 함께 가입**하게 한다. 따로 책임비를 받지 않고, 책임과 보험을 한 번에 해결한다.
- **앱 안에서 예약한 건만 보험으로 보장**한다.
- 중개 플랫폼이라 앱 밖에서 수수료 없이 직거래할 위험이 있는데, 보험 보장 때문에 보호자와 시터 모두 앱 안에서 예약할 이유가 생긴다.

### 시터는 프리랜서

- 다양한 법적 이유로 시터를 고용하지 않고 프리랜서로 운영한다.
- 시터는 신청하고 심사를 통과하면, **가격을 직접 정하고, 일할 수 있는 날과 쉬는 날도 직접 설정**한다.
- 고용으로 보일 수 있는 교육은 하지 않는다. 대신 가입할 때 시팅 팁을 간단한 퀴즈로 풀고 넘어간다.

### 신원 확인은 인증으로

- 범죄 기록을 요구하는 것은 법적으로 불가능하므로 받지 않는다.
- 대신 **본인 인증, 계좌 인증, 거주지 인증**으로 신원을 확인한다. 거주지 인증은 "같은 아파트" 태그의 근거로도 쓰인다.

### 산책부터 시작

- 현재 해석으로는 산책은 합법이고, 집에서 맡아 돌보는 것은 불법(위탁관리업 등록 필요)으로 간주된다.
- 관련 민원을 넣어두었고 회신을 기다리는 중이다. 그때까지는 산책 서비스에 집중한다.

## 7. 마케팅 방향

두 가지를 동시에 알린다.

1. **서비스 홍보:** 모두돌봄이 무엇을 해주는지 알린다.
2. **필요성 알리기:** 강아지가 매일 산책해야 하는 이유, 낮 동안 혼자 남겨지는 강아지에게 이 서비스가 왜 필요한지를 보호자가 납득하게 만든다.

기존 앱들이 충분히 쓰이지 못한 큰 이유가 마케팅 부족이었던 만큼, 수요 자체를 키우는 캠페인을 초기부터 함께 진행한다.
