# 모두돌봄 (ModuDolbom)

동네 반려견 보호자와 산책 시터를 이어주는 매칭 플랫폼.

> 현재 기획 단계입니다. 아래 내용은 논의 중인 방향이며 확정된 사양이 아닙니다.

## 왜 만드나

- **서울은 반려견 돌봄 시장으로 밀도가 높다.** 서울에 등록된 반려견은 약 61만 마리로, 토론토(약 4.6만 마리)의 약 15배다. 북미의 Rover는 넓은 땅에서 성공했지만, 서울은 좁은 지역에 수요가 몰려 있어 매칭에 오히려 유리하다.
- **기존 서비스의 검색이 불편하다.** 검색 순위의 기준이 불투명하고, 리뷰가 없는 신규 시터는 가격을 최저로 내려야만 노출된다. 급하게 시터를 구할 때는 여러 명에게 일일이 메시지를 보내야 한다.

## 핵심 기능 (구상)

- **골라진 후보, 한 번에 요청:** 조건(위치, 강아지 크기, 날짜·시간)을 넣으면 거리, 리뷰, 가격을 종합해 가장 잘 맞는 시터 3~10명이 뜬다. 보호자는 여러 명을 체크해 한 번에 요청을 보낸다.
- **대화 후 확정:** 시터는 대화를 시작하거나 거절할 수 있다. 보호자와 짧게 대화하고 조건이 맞으면 확정되며, 나머지 요청은 자동으로 닫힌다.
- **다양한 후보 노출:** 유명 시터, 아주 가까운 시터, 신규 시터(최소 2명), 저장한 "내 시터"가 섞여서 뜬다.
- **같은 아파트 태그:** 보호자와 같은 단지에 사는 시터를 표시한다.
- **시터 분석 페이지:** 시터가 자기 노출 수, 프로필 조회 수, 요청부터 확정까지의 전환을 확인한다.
- **앱 예약만 보험 보장:** 보험사와 제휴해, 앱 안에서 예약한 건만 보장한다. 보호자는 안심할 수 있고, 앱 밖 직거래도 막는다.

## 운영 원칙

- **시터는 프리랜서다.** 가격과 일정을 시터가 직접 정하고, 회사는 업무를 지시하거나 교육하지 않는다. 가입할 때 시팅 팁 퀴즈만 푼다.
- **신원 확인은 인증으로 한다.** 본인 인증, 계좌 인증, 거주지 인증을 쓰고, 범죄 기록은 요구하지 않는다(법적으로 불가).
- **산책부터 시작한다.** 현재 해석상 산책은 합법이고, 집에서 맡아 돌보는 건 불법으로 간주된다. 관련 민원 회신을 기다리는 중이다.
