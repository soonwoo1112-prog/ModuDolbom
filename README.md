# 모두돌봄 (ModuDolbom)

**우리 동네 이웃이 내 강아지를 산책시켜 주는 앱.**

같은 동네, 같은 아파트에 사는 사람들끼리 반려견 산책을 맡기고 맡는 중개 플랫폼입니다.

> **상태:** 기획 단계입니다. 아래 내용은 논의 중인 방향이며 확정된 사양이 아닙니다.

## 문제

서울에는 약 61만 마리의 반려견이 살고, 1인 가구는 계속 늘고 있습니다. 보호자가 일하는 낮 동안 혼자 오래 남겨지거나 산책을 제대로 못 하는 강아지가 많지만, 지금의 대안은 모두 아쉽습니다.

- **가족·친구:** 믿을 수 있지만, 자주 부탁하기엔 부담스럽습니다.
- **강아지 유치원·호텔:** 데려다주고 데려와야 하고, 비쌉니다.
- **기존 앱:** 가격은 적당하지만, 모르는 사람에게 맡기기엔 믿음이 가지 않습니다.

## 해결

당근마켓이 "같은 동네 사람과 거래한다"는 아이디어로 중고거래의 불신을 풀었듯이, 모두돌봄은 **동네 이웃**에게 산책을 맡깁니다.

- **보호자**는 같은 동네, 같은 아파트에 사는 이웃에게 믿고 맡깁니다.
- **시터**는 동네에 사는 누구나 될 수 있습니다. 점심시간이 한가한 주부, 수업 없는 날의 대학생처럼요.
- 회사가 시터를 고용하는 산책 대행이 아니라, 이웃을 연결하는 **중개 플랫폼**입니다. 가격과 일정은 시터가 직접 정합니다.

## 주요 기능

- **한 번에 여러 시터에게 요청:** 거리, 리뷰, 가격을 종합해 잘 맞는 시터 3~10명을 골라 보여주고, 보호자는 여러 명에게 한 번에 요청합니다. 한 명과 확정되면 나머지 요청은 자동으로 닫힙니다.
- **신규 시터도 노출:** 검색 결과에 신규 시터 1~2명을 항상 포함해, 가격을 내리지 않아도 자리 잡을 수 있습니다.
- **같은 아파트 태그:** 보호자와 같은 단지에 사는 시터를 표시합니다.
- **동네 소셜:** 산책 로그와 강아지 사진을 나누는 피드, 동네 애견인 커뮤니티가 있습니다.
- **산책 기록:** 실시간 GPS 위치 확인, AI 추천 경로, 사진·경로·배변 기록이 남는 산책 로그를 제공합니다.
- **앱 예약만 보험 보장:** 펫보험사와 제휴해, 앱 안에서 예약한 건만 보험으로 보장합니다.
